# Agent Entry Point

This repository contains the public ABPIV Docusaurus site, shared analytics infrastructure, n8n forms infrastructure, the ABPIV creative-production brand system, and their agent operating context.

## Start Here

1. Read the canonical [`agents/context/CONTEXT.md`](agents/context/CONTEXT.md).
2. Select the owning domain in [`agents/context/ROUTING.md`](agents/context/ROUTING.md).
3. Use [`agents/context/GLOSSARY.md`](agents/context/GLOSSARY.md) for canonical repository and agent-lifecycle terms.
4. Load only the relevant entries from the [`repository map`](agents/context/references/repository-map.md).
5. Before changing files, read the [`verification reference`](agents/context/references/verification.md) and [`Git policy`](agents/context/references/git-policy.md).

The canonical context contains the binding layer, secret-handling, analytics-origin, Project, and handoff boundaries. Historical root plans and handoffs are not default operating context.
