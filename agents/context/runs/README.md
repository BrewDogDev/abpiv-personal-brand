# Run History Registry

## Registered History

- [`legacy/`](legacy/README.md): non-authoritative root, Kilo, and Superpowers agent history preserved with provenance and canonical replacements.

Retain a run only when auditability, reproducibility, comparison, or recurring production use justifies it. Run artifacts are Layer 4 evidence, never stable policy or active Project control state. Legacy history must remain clearly labeled and preserved during migration.
