# Creative Production Assets

Reusable brand systems, prompt contracts, and source assets for Creative Production work tied to this repository.

## Brand Systems

- `brand-systems/abpiv/` - Allan B. Pedin IV / ABPIV personal brand system.

Each brand system should keep:

- `README.md` - human-readable design system source of truth.
- `SKILL.md` - agent entry point for brand-aware creative or production work.
- `creative-production.manifest.json` - machine-readable adapter for Creative Production paths.
- `prompt-contract.md` - reusable prompt block and path-specific launcher prompts.
- `style-intake.json` - compact style choices suitable for Creative Production intake widgets.
- `assets/`, `fonts/`, `preview/`, and `ui_kits/` - portable visual source material.
